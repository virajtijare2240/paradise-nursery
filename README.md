
# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is an online plant shopping application developed using React.js. It allows customers to browse different categories of houseplants, view product details, and add their favourite plants to a shopping cart.

The application provides an interactive shopping experience with dynamic cart management and automatic price calculations.

## Features

- Attractive landing page with background image.
- About Us page describing the company.
- Three categories of houseplants.
- 18 unique plant products.
- Product images, names, and prices.
- Add to Cart functionality.
- Dynamic shopping cart counter.
- Increase and decrease product quantities.
- Remove products from the shopping cart.
- Automatic individual and total price calculation.
- Checkout Coming Soon notification.
- Continue Shopping functionality.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Router DOM
- Vite

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/virajtijare2240/paradise-nursery.git
```

2. Open the project folder:

```bash
cd paradise-nursery
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm run dev
```

5. Open the local URL provided by Vite.
